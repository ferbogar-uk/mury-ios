# MURY reference-led replay flow / v1.3

The user-supplied four-phone reference sets the visual direction. Activity -> replay setup -> full-screen playback -> share. The comparison board is MURY-replay-flow.svg/png. Individual editable screen masters and previews are under screens/.

Rubik 400/600/700 and the corrected route-and-pin symbol remain selected. Light activity/setup/share surfaces use baby-blue navigation and blood-red actions. Playback uses full-bleed concept city imagery, a red symbol with white wordmark, compact top metrics, a white route core inside a red band/glow and a red progress marker with white border. Compact share preview preserves logo/text proportions.

A stylised illustrative map and repeated concept-city thumbnails stand in for actual activity media. AR is a sample avatar monogram. All activity values are sample data. City imagery is generated concept artwork, not actual map output or geographic evidence. Share destinations are labels, not working integrations or official provider logos.

These are static brand design assets, not implemented app screens, video generation, GPS, map SDK, playback or social export. Store templates need real release screenshots. Native implementation, gesture/interaction tests, accessibility semantics and real media are separate development work.
