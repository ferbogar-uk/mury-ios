# MURY platform icons

Use mury-appstore-1024.png as the flat opaque RGB marketing master. AppIcon.appiconset provides conventional iPhone/iPad sizes and a 1024 marketing image. The SVG masters are editable; keep the square artwork unrounded and let the operating system mask it.

Icon-Composer-layers contains separate PNG/SVG background and transparent foreground inputs for default, dark and tinted appearances. Import and configure these in Apple Icon Composer/Xcode; an untested proprietary .icon document has not been fabricated. The PNG asset catalog is supplied as a conventional import route. Verify on the actual iOS SDK/device before release.

Android res includes legacy densities and adaptive vector/background XML with the symbol kept in the safe central region. Windows ICO and macOS ICNS are supplementary. None of these resources has been submitted to a store or tested in a device build.

Sources checked 1 November 2026: https://developer.apple.com/design/human-interface-guidelines/app-icons and https://developer.apple.com/help/app-store-connect/manage-app-information/add-an-app-icon/
