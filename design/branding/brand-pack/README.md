## Use the right source
- Main logo on light: 01-Logos/mury-horizontal-primary.svg. On dark: mury-horizontal-dark.svg. For a single ink use -red, -white or -black.
- Logo SVGs are fully outlined: no font installation or embedded raster is needed. Template text is editable and uses Rubik; install the included static fonts or load the variable web font before editing. Do not install variable and static versions together if your design tool reports conflicting family names.
- The primary app icon is mury-app-blue.svg. Use mury-appstore-1024.png for the flat opaque RGB marketing icon. iOS masks the square master; do not bake rounded corners into it.
- Use dark navigation blue, not red on charcoal. Flat 2D routes use a pale casing; photographic Flyover/replay uses a white core inside a red band and glow. See the contrast table and UI component guide.
- All social metrics are sample data. Replace them with verified activity results before publication. The weekly template has four activity days totalling 42.3 km.
- The supplied brand screen specimens are static layouts, not a functioning app. Store templates are visibly marked as concepts and require real release screenshots; planned Flyover features must not be presented as shipping.

## Scope and completeness
This delivery completes the full asset pack requested after selection of direction 1. It is not another approval-only review set. The latest visual direction follows the user-supplied four-screen activity/replay/share reference. Corrected MURY logo and Rubik remain selected. No existing MURY project files, application assets or implementation were accessed or modified. No executables, build scripts, credentials or app project are included; JSON/CSS/XML are design and native resource files.

Print colours use sRGB masters and approximate unprofiled CMYK values; obtain a printer proof for production. Physical print, actual device/Xcode/Android import and App Store upload acceptance were not tested. Name/domain/trademark clearance is not part of this asset export. No native AI/PSD/PPTX project is implied: editable SVG and vector PDF/EPS are the supplied interchange formats.

INVENTORY.csv includes file sizes and SHA-256 hashes. VERIFICATION.md states the actual checks and limits. Keep Rubik and Lucide/Feather licences with redistributed assets.
